智能体设计一页纸

十二个知识点压缩成四行——能从“聊天 AI”讲到“会自我纠错的客服 Agent”，这篇就算吃透了。

汇总复盘5 分钟
本篇知识地图
Prompt 四板斧2-1 ~ 2-4
人设圈定概率池、范文是最精确的提示词、格式按消费者选、注入要三层防。人设管“怎么说”，范文管“什么感觉”，格式管“能不能直接用”，安全管“别被套话”。
Agent 循环2-5 ~ 2-9
Agent = 模型 + 脚手架：Plan 拆任务、Tool 动手（AI 开条系统跑腿）、Memory 记事、Act 执行。ReAct 三步循环带自我纠错；五种翻车靠五道护栏；Skill 把 SOP 变成肌肉记忆。
效能体系2-10 ~ 2-11
轮数是第一杀手（白板累积，轮数越多重复计费越多）。五层效能优化：提示词瘦身 → 流程收口 → 语义缓存 → 上下文压缩 → 模型分级——帮运营把琐事时间一层层抢回来，每周 20 小时压到六七个小时。
选型矩阵2-12
两轴定选型：任务容错度与复杂度 × 预算等级。最大浪费是全任务旗舰——简单活用经济档，旗舰只干贵活；每季度用自己的题重测，备好备胎模型。
带走的决策清单
  • ✅ 给 AI 下任务前默念四件套：人设、范文、参数、红线——缺哪个补哪个。
  • ✅ 第一批 Agent 工具只上“只读”：查订单、查库存、查物流，写操作后放。
  • ✅ 五道护栏写进框架：循环上限、输出截断、超时控制、中断恢复、转人工闸口。
  • ✅ 把店里三个核心 SOP 写成 Skill：差评处理、售前咨询、发货异常。
  • ✅ 每月看一次账单构成：轮数、单轮 Token、模型档位，哪个异常砍哪个。
📌 本篇带走的四句话
  • 聊天 AI 是顾问，Agent 是员工——员工要配流程、工具和权限。
  • Agent 的工程在脚手架：翻车不怪模型怪框架，护栏和 Skill 是你的主战场。
  • 成本先堵浪费再谈单价：轮数和提示词减半是免费的。
  • 会带人就会带 Agent：你二十年的管理经验，正是这个时代最值钱的技能。

Token：AI 的“计价单位”

搞电商的算账都精。AI 这盘生意的第一步，就是搞明白它按什么单位收你的钱。

交互概念6 分钟
先打个比方

你去发快递，快递公司按重量收费；你找美工做图，美工按张数收费。那 AI 公司按什么收费？按 Token。

Token 是什么？别被这个洋词唬住。你可以把它理解成 AI 眼里的“字块”——AI 读文章、写文章，不是一个字一个字来的，而是一块一块来的。大致的规律是：

  • 一个汉字 ≈ 1 个 Token（常见字有的半个，生僻字可能两个）
  • 一个英文单词 ≈ 1 个 Token，标点符号也算
  • 一句“亲，这款连衣裙有现货哦” ≈ 12~14 个 Token

算一笔电商账

假设你用主流档模型（¥8 / 百万 Token）批量生成商品标题和卖点：

  • 一个 SKU：输入商品参数约 200 Token，输出标题 + 5 条卖点约 300 Token，合计约 500 Token
  • 1000 个 SKU 全店翻新一遍：50 万 Token ≈ 4 块钱
看出来了吧——生成文案这件事，AI 的边际成本几乎为零。真正烧钱的不是写，而是后面会讲到的：客服 Agent 一轮一轮的对话、生图、还有你反复试错改提示词的过程。学会算 Token 账，是管住 AI 成本的第一步。
为什么偏偏按 Token 收费

因为 AI 干活消耗的是算力，而算力消耗和 Token 数基本成正比：读你的输入要算力，一个字一个字往外蹦也要算力。Token 就是它和算力之间最诚实的换算单位。

所以记住这个公式：AI 账单 =（输入 Token + 输出 Token）× 单价。后面讲成本优化时，所有招数本质都是在动这两个数——要么让输入变短，要么让输出变短，要么换个单价便宜的模型干粗活。

📌 本节要点
  • Token = AI 的计价单位，一个汉字约 1 个，输入输出都计费。
  • 账单公式：AI 费用 =（输入 + 输出 Token）× 单价，优化成本就动这三个变量。
  • 文案生成极其便宜：1000 个 SKU 的标题卖点只要几块钱，别在这上面省错地方。
  • 真正的大头在多轮对话和生图，后面的篇章会专门算这两笔账。

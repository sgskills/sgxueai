第三篇章 · 电商 AI 落地实战

产品特征提取：固化生图物理参数

为什么你的 AI 生图总在“漂移”？同一个保温杯，上午出的图是磨砂质感，下午就变成亮面，换个提示词连瓶身弧度都变了。根子不是提示词写得不好——是你从来没给这个产品“录过指纹”。

诗光创作实战8 分钟
生图漂移的根子：产品没有“指纹”

你直接让 AI 画产品图，它每一张都在重新“猜”你的产品：材质猜错、颜色跑偏、轮廓变形、LOGO 自由发挥。十张图十个样，不是 AI 不听话，是你没告诉它“这个产品到底长什么样”——它只能每次现场脑补。

3-1 讲效率、3-2 讲流水线、3-3 讲质检——但质检是出了图再挑毛病，治标不治本。真正治本的一步在生图之前：先把产品的物理参数一次性提取出来，固化成一份《产品特征关键词》。之后所有生图都从同一份关键词出发，产品长相就被锁死了。

⚠️ 这一步是诗光在真实作图业务流里反复打磨出来的特殊经验。市面上讲 AI 生图的课，大多教你“怎么写提示词”，很少讲“提示词之前要干什么”。我自己的答案是：先把产品锁住，再谈风格。不锁产品，风格越花哨，漂移越离谱。
诗光实战业务流 · 两步走
产品特征提取 → 锁特征生图 · 完整业务流
1
拍图：多角度产品实拍
正面、侧面、背面、45° 角、局部特写——拍 4~6 张不同角度的产品照片。不用精修，清晰能看清细节就行。
⬇
2
提取：交给「产品特征提取专家」Agent / Skill
把多角度图片一次性发给它。它就像给产品采集指纹的鉴定员，从七个维度逐项扫描：形态、材质、纹路、色彩、描边轮廓、品牌标识、状态视角——多角度交叉验证，产出一份独一无二的《产品特征关键词》，这就是这个产品的“指纹”。
⬇
3
生图：关键词 + 产品图 + 参考案例 → 「作图大师」Agent / Skill
把特征关键词、产品原图和你看中的竞品参考图一起发给作图大师。它负责拆解参考图的构图、光影、氛围，再把你的固定特征词严丝合缝地嵌进去，输出一条 300~1000 字的生图提示词。
⬇
4
出图：提示词喂给生图工具
即梦、MJ、SD——工具随便换，关键词不动。产品的“真”由关键词保证，画面的“美”由参考案例决定，两件事终于分开了。
关键词长什么样：固定词锁死，场景词随便换

关键词的精髓是把产品特征和场景元素分开。产品特征写成“固定词”，锁死不动；背景、光影、氛围写成“场景词”，随便换。同一把锁，配无数把钥匙：

🔒 固定词产品特征（锁死不动）
形态圆柱直筒杯身，上窄下宽 5° 微锥，一体成型无接缝
材质316 不锈钢磨砂面不是“金属感”这种虚词
色彩深邃海军蓝，潘通 5395C不是“蓝色”
品牌标识杯身中下 1/3 处，激光雕刻 LOGO，竖排
🔓 场景词画面氛围（随便换）
背景大理石台面 / 原木书桌 / 户外露营地
光影清晨侧逆光 / 影棚柔光箱 / 黄昏暖调
氛围商务通勤 / 居家慵懒 / 运动户外
构图居中特写 / 三分法留白 / 俯拍平铺

感受一下差别：“一个蓝色保温杯”和“316 不锈钢磨砂面、深邃海军蓝（潘通 5395C）、上窄下宽 5° 微锥杯身、杯身中下 1/3 处激光雕刻竖排 LOGO 的保温杯”——前者 AI 随便发挥，后者它只能照办。关键词的颗粒度，就是生图的稳定度。

七个维度，一个不能漏
① 形态轮廓、比例、结构——产品的骨架
② 材质金属/磨砂/亮面/织物——质感的真相
③ 纹路表面纹理、肌理走向、图案细节
④ 色彩精确到色号级别，杜绝“大概是蓝色”
⑤ 描边轮廓边缘形态、线条粗细、倒角处理
⑥ 品牌标识LOGO 位置、工艺、颜色——侵权红线
⑦ 状态视角开合状态、使用形态、标准展示角度
三条使用要点
  • 多角度交叉验证：只发一张正面图，AI 会脑补侧面和背面——脑补就会出错。4~6 个角度一起发，让它对着照片“核实”而不是“想象”。
  • 固定词锁死、场景词常换：改场景不用重提特征，关键词一次建好、长期复用。上新品才需要新建关键词，换主图风格只需要换场景词和参考案例。
  • 关键词入库，变成团队资产：每个 SKU 一份特征关键词，放进团队提示词资产库（5-7 节会专门讲）共享。美工离职了，关键词还在——产品长相的标准不跟着人走。
📌 本节要点
  • 生图漂移的根子：没固化产品特征，AI 每张图都在重新“猜”你的产品。
  • 两步业务流：多角度实拍 → 特征提取 Agent 产出七维度关键词 → 关键词+产品图+参考案例 → 作图 Agent 生成提示词 → 出图。
  • 固定词锁产品，场景词换氛围：产品的“真”和画面的“美”分开管理，关键词颗粒度决定生图稳定度。
  • 关键词是团队资产：一次提取、长期复用、全店共享——这是诗光在实战里打磨出来的心得，先锁产品，再谈风格。
